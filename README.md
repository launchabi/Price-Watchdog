# Price-Watchdog

A personal price-drop tracker. You can paste in a product URL and the website checks its price on a schedule, stores the history and charts it over time, notifying the user when price drops below a target value set by the user.

## Build phases

### Phase 1 - Frontend Only (Mock data)
- Build out a dashboard of watched products as cards, each with a mock price history chart
- Form to add a product (stored in local data)
- Target price input
